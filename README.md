# Counter App

A simple counter made with HTML, CSS and JavaScript.

## Features

- **+** adds 1 to the count
- **-** subtracts 1 from the count
- **Reset** sets the count back to 0

## Files

- `index.html` – the page structure
- `style.css` – the styling
- `script.js` – the counter logic

## How to Run

Open `index.html` in any web browser.

## What I Learned

- Selecting elements with `document.getElementById`
- Handling button clicks with `addEventListener`
- Updating text on the page with `textContent`
